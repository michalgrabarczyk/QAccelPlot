    Detailed Description¶

    PlotSeries owns the integration shared by every plot type: axis bindings, plot-area layout, data-range reporting, legend metadata, and a common C++ data-setting API backed by the series' data points. Concrete series define their data point layout, rendering, and hit testing.

    setData(), setDataF(), and postData() take interleaved values, one data point after another, in the layout of the series:

    Series Data point Values
    LineCurve (x, y) 2
    PointCloud (x, y) 2
    RectangleSeries (x1, y1, x2, y2) 4
    BarSeries (position, value) 2
    BandSeries (x, low, high) 3
    ErrorBarSeries (x, y, low, high) 4
    HeatmapSeries cell value 1

    The buffer holds count times that many values. A HeatmapSeries takes its cells row by row, columns per row. Series-specific setters take other layouts, such as point values, categories, or ranged bars.

    See also: LineCurve, PointCloud, RectangleSeries, BarSeries, BandSeries, ErrorBarSeries, HeatmapSeries, QAccelPlot

    Public Types Documentation¶

    enum LegendSymbol¶

    Supported default legend symbols. 

    enum QAccelPlot::PlotSeries::LegendSymbol {
    Line,
    Fill,
    Marker
};

    Line draws the series line style and marker, Fill a filled swatch, and Marker only the series marker shape (used by unconnected series such as PointCloud).

    enum MarkerShape¶

    Marker shapes shared by every series that draws markers. 

    enum QAccelPlot::PlotSeries::MarkerShape {
    None,
    Circle,
    Square,
    Diamond,
    TriangleUp,
    TriangleDown,
    TriangleLeft,
    TriangleRight,
    Cross,
    XCross,
    HLine,
    VLine,
    Star,
    Asterisk,
    Pixel,
    Hexagon,
    Pentagon
};

    Every shape except Pixel fits within a square whose half-width is the marker size. The shaders select a shape by this value minus one, so append new shapes at the end and never reorder or insert. Series that always draw markers, such as PointCloud, do not accept None.
