    property int tickCount
    Target number of major tick marks. Actual count is adjusted for "nice" values. Default: 5.
    property QColor tickLabelColor
    Optional color of tick labels. When invalid, the tickColor is used.
    property QFont tickLabelFont
    Font used to render tick labels. Default: application default font.
    property TickLabelFormatter * tickLabelFormatter
    Optional custom formatter for tick labels. When nullptr the defaultNumericTickLabelFormatter is used.
    property qreal tickLabelPadding
    Spacing in pixels between a tick mark and its label. Default: 5.
    property qreal tickLabelRotation
    Rotation angle in degrees applied to each tick label. Default: 0.
    property qreal tickLength
    Convenience setter for both tickLengthIn andtickLengthOut simultaneously.
    property qreal tickLengthIn
    Length in pixels of the portion of a major tick that extends into the plot area. Default: 8.
    property qreal tickLengthOut
    Length in pixels of the portion of a major tick that extends outside the plot area. Default: 8.
    property qreal tickWidth
    Width in pixels of major tick mark lines. Default: 2.

    Detailed Description¶

    Accessible via the Axis::ticker CONSTANT property. Changes are applied on the next paint event.

    See also: Axis
