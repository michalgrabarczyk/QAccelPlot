QAccelPlot API reference

QAccelPlot is a hardware-accelerated 2D plotting library for Qt Quick. It provides QML-friendly plot components backed by C++17 and the Qt Scene Graph.

This reference documents the public C++ classes that implement the QML API. For installation instructions and task-oriented examples, start with the Getting started guide.

Quick start

import QtQuick
import QAccelPlot as QAccelPlot
QAccelPlot.Plot {
id: plot
xAxis: QAccelPlot.Axis {
viewportMin: 0
viewportMax: 10
side: QAccelPlot.Axis.Bottom
}
yAxis: QAccelPlot.Axis {
viewportMin: -1
viewportMax: 1
side: QAccelPlot.Axis.Left
}
QAccelPlot.LineCurve {
xAxis: plot.xAxis
yAxis: plot.yAxis
color: "darkorange"
lineWidth: 2
Component.onCompleted: setData([
Qt.point(0, 0),
Qt.point(2.5, 0.8),
Qt.point(5, -0.6),
Qt.point(7.5, 0.4),
Qt.point(10, 0)
])
}
}

The QML Plot component is the recommended application-level entry point. It wraps PlotView, the native plot canvas documented in this reference.

Key types

  • PlotView — plot canvas, layout, navigation, coordinate conversion, grid, and series collection.
  • QAccelPlot::Axis — visible ranges, scaling, ticks, labels, panning, and zooming.
  • QAccelPlot::LineCurve — GPU-rendered lines, markers, data ingestion, effects, transitions, and hover handling.
  • QAccelPlot::RectangleList — hardware-accelerated collections of data-space rectangles.
  • QAccelPlot::DataAnchor — positions QML overlays at data coordinates.
  • QAccelPlot::PlotMouseEvent — mouse positions expressed in plot and data coordinates.

Styling and formatting

  • Line styles: QAccelPlot::SolidLine, QAccelPlot::DashLine, and QAccelPlot::NoLine.
  • Curve effects: QAccelPlot::GradientFill and QAccelPlot::GradientStroke.
  • Transitions: QAccelPlot::DrawTransition and QAccelPlot::MorphTransition.
  • Tick labels: QAccelPlot::NumericTickLabelFormatter, QAccelPlot::DateTimeTickLabelFormatter, QAccelPlot::LogTickLabelFormatter, and QAccelPlot::TextTickLabelFormatter.

Feeding curve data

Choose the simplest API appropriate for the data source:

  • Use setData() for QML data or conventional C++ point containers.
  • Use the moved-buffer setDataF() overload for large interleaved std::vector<float> buffers produced on the curve's thread.
  • Use postData() to transfer a completed buffer safely from a worker thread.
  • Use setDataFNoRange() only when axis data ranges are maintained separately.

See the Performance guide for a detailed comparison of the available data paths.

Runtime requirements

QAccelPlot requires Qt 6.2 or newer and a hardware Qt Quick Scene Graph backend, such as OpenGL, Direct3D, Vulkan, or Metal. The Qt Quick software backend cannot render the custom curve shaders.

Never mutate a QQuickItem directly from a worker thread. Use LineCurve::postData() or queue the operation to the item's thread.
